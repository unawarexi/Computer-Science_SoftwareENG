# Go Programming: 5-Month Learning Guide

This guide provides a structured 5-month curriculum to learn Go from fundamentals to advanced topics.

## Month 1: Go Fundamentals
**Goal:** Understand the basics of Go syntax, variable declarations, and control structures.
- **Week 1:** Introduction to Go (Installation, Workspace setup, Hello World)
- **Week 2:** Variables, Constants, and Basic Data Types (int, float, string, boolean)
- **Week 3:** Control Structures (if/else, switch statements)
- **Week 4:** Loops (for loops, range)

## Month 2: Core Concepts
**Goal:** Master functions, pointers, and foundational data structures.
- **Week 5:** Functions (Declarations, Multiple return values, Variadic functions)
- **Week 6:** Pointers (Addresses, Dereferencing, Passing by reference)
- **Week 7:** Arrays and Slices (Declaration, Manipulation, append, copy)
- **Week 8:** Maps (Key-value pairs, iterating, deleting)

## Month 3: Object-Oriented Patterns in Go
**Goal:** Learn how Go handles structures and interfaces instead of traditional classes.
- **Week 9:** Structs (Defining, Methods on structs, Composition)
- **Week 10:** Interfaces (Implicit implementation, Empty interface, Type assertions)
- **Week 11:** Error Handling (The `error` interface, Custom errors, `panic` and `recover`)
- **Week 12:** Small Console Project (Apply Month 1-3 concepts)

## Month 4: Concurrency and Modularity
**Goal:** Master Go's powerful concurrency model and project organization.
- **Week 13:** Goroutines (Basic concurrency, WaitGroups)
- **Week 14:** Channels (Unbuffered/buffered, Select statement, Worker pools)
- **Week 15:** Packages and Modules (Creating modules, importing, `go.mod`)
- **Week 16:** Standard Library (fmt, os, io, strings, time)

## Month 5: Advanced Topics, Testing, and Projects
**Goal:** Write robust, tested code and build a capstone project.
- **Week 17:** Testing (The `testing` package, Unit tests, Table-driven tests, Benchmarks)
- **Week 18:** Advanced Topics (Context package, Generics, JSON Parsing)
- **Week 19:** Capstone Project Planning & API Design (Building a RESTful API with `net/http`)
- **Week 20:** Capstone Project Implementation (Connecting to a database, structuring a web app)
