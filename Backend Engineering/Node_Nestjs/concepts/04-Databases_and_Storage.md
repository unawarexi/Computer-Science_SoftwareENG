# Databases & Storage

## Overview
Polyglot persistence strategies for different data access patterns in an e-commerce platform.

## Topics
1. **Relational Databases (PostgreSQL) & Prisma**
   - Strong ACID properties.
   - Use cases: Financial transactions, User accounts, Orders, Inventory count.
   - Prisma ORM for type-safe database access and schema migrations.

2. **NoSQL Document Stores (MongoDB)**
   - Flexible schema for unstructured or semi-structured data.
   - Use cases: Product catalog (diverse attributes per category), User reviews, Shopping carts.

3. **Wide-Column Stores (Cassandra)**
   - High write throughput and linear scalability.
   - Use cases: Clickstream data, activity logs, time-series data for analytics.
