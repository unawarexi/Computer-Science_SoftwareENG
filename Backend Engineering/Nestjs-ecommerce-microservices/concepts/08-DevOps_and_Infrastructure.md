# DevOps & Infrastructure

## Overview
Managing infrastructure as code and orchestrating containers.

## Topics
1. **Docker & Containerization**
   - Multi-stage builds for NestJS applications.

2. **Kubernetes (K8s)**
   - Orchestrating microservices.
   - Deployments, StatefulSets (for databases), Services, and Ingress controllers.
   - Horizontal Pod Autoscaling (HPA) based on CPU/Memory or custom metrics.
   - Secrets and ConfigMaps.

3. **Terraform (IaC)**
   - Provisioning cloud resources (AWS, GCP, Azure).
   - Managing managed databases (RDS), Kubernetes clusters (EKS/GKE), and networking (VPC).
