# Dart & Flutter: 5-Month Learning Guide

This guide provides a structured 5-month curriculum to learn Dart programming from scratch and transition seamlessly into building cross-platform apps with the Flutter framework.

## Month 1: Dart Fundamentals
**Goal:** Understand the basics of Dart syntax, control flow, and functions.
- **Week 1:** Introduction to Dart (Variables, Data Types, Setup)
- **Week 2:** Operators and Expressions
- **Week 3:** Control Flow (If/Else, Loops, Switch)
- **Week 4:** Functions (Parameters, Return Types, Arrow Functions)

## Month 2: Object-Oriented & Advanced Dart
**Goal:** Master Object-Oriented Programming (OOP) and asynchronous operations in Dart.
- **Week 5:** OOP Basics (Classes, Objects, Constructors)
- **Week 6:** Advanced OOP (Inheritance, Polymorphism, Encapsulation)
- **Week 7:** Mixins, Abstract Classes, and Static Members
- **Week 8:** Asynchronous Dart (Futures, `async`/`await`, Error Handling)

## Month 3: Flutter Basics & UI Foundations
**Goal:** Dive into Flutter and build beautiful user interfaces.
- **Week 9:** Introduction to Flutter (Widget Tree, Stateless vs Stateful)
- **Week 10:** Basic UI Widgets (Text, Container, Row, Column)
- **Week 11:** Common UI Elements (Buttons, Images, Forms)
- **Week 12:** Scrolling and Complex Layouts (ListView, GridView, Slivers)

## Month 4: State Management & Navigation
**Goal:** Learn how to manage app state and navigate between screens.
- **Week 13:** Ephemeral State (setState) & InheritedWidget
- **Week 14:** Global State Management (Provider, Riverpod)
- **Week 15:** Advanced State (BLoC or GetX)
- **Week 16:** Navigation and Routing (Navigator 2.0, GoRouter)

## Month 5: Advanced Flutter & Projects
**Goal:** Master animations, network requests, and build a capstone project.
- **Week 17:** Animations (Implicit and Explicit)
- **Week 18:** Networking (HTTP, REST APIs, JSON Serialization)
- **Week 19:** Backend Integration (Firebase or Supabase)
- **Week 20:** Capstone Project Implementation (Publishing to App Store / Google Play)
