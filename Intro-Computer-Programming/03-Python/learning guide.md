# 🐍 Python 10-Month Learning Guide

Welcome to your structured 10-month Python journey! This guide takes you from the basics of programming to advanced topics, culminating in a capstone project. By following this track, you'll develop a robust understanding of Python, software engineering principles, and practical application building.

---

## 📅 Month 1: Python Fundamentals
**Goal:** Understand the basics of Python syntax, data types, and fundamental operations.
* **Topics:**
  - Setting up the Python environment
  - Variables and Data Types (`datatypes.py`, `variables.py`)
  - Basic I/O (`hello world.py`, `intro.md`)
  - Operators and Type Conversion (`operators.py`, `type_conversion.py`)
* **Focus:** Getting comfortable with writing simple scripts and running them.

## 📅 Month 2: Control Flow
**Goal:** Learn how to control the execution path of your programs.
* **Topics:**
  - Conditional Statements (`if`, `elif`, `else`) (`conditionals.py`)
  - Looping (`for`, `while`) (`loops.py`)
  - Breaking, Continuing, and Passing in loops
* **Focus:** Building logic that reacts dynamically to data and user input.

## 📅 Month 3: Functions and Methods
**Goal:** Understand how to write reusable code blocks and utilize Python's built-in methods.
* **Topics:**
  - Defining functions and passing arguments (`functions.py`)
  - Return statements and variable scope
  - Built-in functions (`builtin-func.py`)
  - String and Math Methods (`StringMethods.py`, `mathMethods.py`)
* **Focus:** Modularizing your code and leveraging standard methods for cleaner logic.

## 📅 Month 4: Data Structures
**Goal:** Master the core ways Python stores and organizes data.
* **Topics:**
  - Lists and List Methods (`lists.py`, `ListMethods.py`)
  - Dictionaries and Dictionary Methods (`dictionaries.py`, `dictMethods.py`)
  - Tuples (`tuples.py`)
  - Sets (`sets.py`)
* **Focus:** Knowing when to use which data structure for optimal performance and organization.

## 📅 Month 5: Object-Oriented Programming (OOP)
**Goal:** Transition to object-oriented design patterns.
* **Topics:**
  - Classes and Objects (`classes.py`, `objects.py`)
  - Inheritance (`inheritance.py`)
  - Polymorphism (`polymorphism.py`)
  - Encapsulation (`encapsulation.py`)
* **Focus:** Modeling real-world concepts into code using OOP paradigms.

## 📅 Month 6: Modules and File Handling
**Goal:** Learn to interact with the file system and organize larger codebases.
* **Topics:**
  - Importing modules and libraries (`import_modules.py`, `libraries.py`)
  - File reading and writing (`read-write.py`, `file_handling`)
  - JSON and CSV parsing (`json.py`, `csv.py`)
  - Regular Expressions (`regex.py`)
  - Error and Exception Handling (`error_handling.py`)
* **Focus:** Making your programs interact safely with external data and files.

## 📅 Month 7: Advanced Data Structures
**Goal:** Implement complex data structures from scratch.
* **Topics:**
  - Linked Lists (`linked-lists.py`)
  - Doubly Linked Lists (`doubly linked lists/`)
  - Stacks (`stacks.py`)
  - Queues (`queues.py`)
* **Focus:** Understanding algorithmic efficiency and underlying data structure mechanics.

## 📅 Month 8: Advanced Python Concepts
**Goal:** Unlock the "Pythonic" way of writing advanced and highly optimized code.
* **Topics:**
  - Decorators and Closures
  - Generators and Iterators
  - Context Managers (`with` statement)
  - Concurrency & Threading basics
* **Focus:** Writing high-performance, elegant, and standard Python code.

## 📅 Month 9: Projects and Automation
**Goal:** Apply everything you've learned to build real-world applications and automate tasks.
* **Topics:**
  - Scripting and Automation (`Automate.py`)
  - Building basic applications (`calc.py`, `contact.py`)
  - Data processing and iteration (`iterate.py`, `func.py`)
* **Focus:** Moving from theoretical learning to practical problem-solving.

## 📅 Month 10: Capstone Project
**Goal:** Build a comprehensive, portfolio-ready project from start to finish.
* **Topics:**
  - Project planning and system design
  - Incorporating all learned topics (OOP, File Handling, advanced structures)
  - Code documentation and testing
* **Focus:** Showcasing your Python mastery.

---
*Happy Coding! Proceed steadily, practice daily, and don't hesitate to build things along the way!*
