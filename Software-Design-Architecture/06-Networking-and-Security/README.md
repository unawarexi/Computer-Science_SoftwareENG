# 06 - Networking and Security

This module covers the essentials of networking and security for software architects. You'll learn how to design secure, reliable systems and APIs.

## What You'll Learn

- Protocols, OSI Model, DNS, and web communication
- API design (REST, GraphQL, gRPC, API Gateways)
- Web security (XSS, CSRF, SQLi, CORS, CSP, JWT, OAuth2/OIDC)
- Secure architecture (Threat modeling, RBAC, Secrets Management)
- Infrastructure security (Zero Trust, Service Mesh, WAF, DDoS Mitigation)

## Weekly Breakdown

**[Week 1: Protocols & Web Communication](./01-protocols.md)**
- OSI Model, TCP/IP, UDP, DNS
- HTTP/HTTPS, HTTP/3, WebSockets

**[Week 2: API Design and Gateways](./02-api-design.md)**
- REST, GraphQL, gRPC, Webhooks
- API Gateways, Rate Limiting, Throttling

**[Week 3: Security Essentials](./03-security-essentials.md)**
- XSS, CSRF, SQLi, CORS, CSP, HSTS
- JWT, OAuth2, OpenID Connect (OIDC), TLS

**[Week 4: Secure Architecture Design](./04-secure-architecture.md)**
- Threat modeling (STRIDE)
- Principle of least privilege, Defense in Depth, RBAC vs ABAC
- Secure storage, password hashing, Secrets Management

**[Week 5: Advanced Infrastructure Security](./05-advanced-infrastructure.md)**
- Zero Trust Architecture
- Service Mesh and mTLS
- WAF and DDoS mitigation

---

By the end, you'll be able to design and secure modern software systems.
