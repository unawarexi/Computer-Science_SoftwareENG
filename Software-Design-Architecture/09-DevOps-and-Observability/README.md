# 09 - DevOps and Observability

Master the practices and tools that enable continuous delivery, deployment, and monitoring of modern software systems.

## What You'll Learn

- CI/CD pipelines and release strategies (Blue-Green, Canary)
- Containerization and DevSecOps (Docker, Security Scanning)
- Infrastructure as Code (IaC) and GitOps (Terraform, ArgoCD)
- Container orchestration (Kubernetes, Helm)
- The Three Pillars of Observability (Metrics, Logs, Traces)
- Site Reliability Engineering (SRE) culture and metrics

## Weekly Breakdown

**[Week 1: CI/CD Pipelines and Release Strategies](./01-cicd-and-release-strategies.md)**
- GitHub Actions, Jenkins, Blue-Green deployments, Canary releases, Feature flags

**[Week 2: Containerization and DevSecOps](./02-containerization.md)**
- Docker, multi-stage builds, SAST/DAST, dependency & container scanning

**[Week 3: Infrastructure as Code (IaC) & GitOps](./03-iac-and-gitops.md)**
- Terraform, immutable infrastructure, pull-based deployments, ArgoCD

**[Week 4: Kubernetes Orchestration](./04-kubernetes-orchestration.md)**
- Architecture, Pods, Deployments, Services, Ingress, Helm

**[Week 5: Observability Deep Dive](./05-observability.md)**
- Metrics (Prometheus, Grafana), Logs (ELK, Loki), Distributed Traces (OpenTelemetry, Jaeger), Alerting (PagerDuty)

**[Week 6: Site Reliability Engineering (SRE)](./06-sre.md)**
- SLIs, SLOs, SLAs, Error Budgets, toil reduction, blameless postmortems

---

By the end, you'll be able to build, deploy, and monitor robust systems.
