# 07 - Distributed Systems

Dive into the world of distributed systems. Learn the core concepts, patterns, and challenges of building systems that span multiple machines.

## What You'll Learn

- Distributed computing fundamentals
- Communication patterns (queues, pub/sub, event sourcing)
- CAP theorem and tradeoffs
- Handling failures in distributed systems

## Weekly Breakdown

**[Week 1: Core Concepts](./01-core-concepts.md)**

- Distributed computing, time & clocks, consensus

**[Week 2: Communication Patterns](./02-communication-patterns.md)**

- Message queues (RabbitMQ, Kafka), Pub/Sub, Event sourcing, protocols, concurrency control, parallel databases, distributed databases, RMI, MPI, bully and ring algorithms, remote procedure call rpc, code and resource migration, migration models, fault tolerance

**[Week 3: CAP Theorem in Depth](./03-cap-theorem.md)**

- Consistency vs availability
- Design tradeoffs

**[Week 4: Failures in Distributed Systems](./04-failures.md)**

- Retry logic, circuit breakers, idempotency

**[Week 5: Architectures & OS Models](./05-architectures-and-os-models.md)**

- CORBA, middleware/network OS, P2P/client-server models, software agents

**[Week 6: Advanced Distributed Databases](./06-advanced-databases.md)**

- Distributed transactions, mutual exclusion, recovery, fragmentation, query processing, replication

**[Week 7: Security in Distributed Systems](./07-security.md)**

- Distributed security challenges and security mechanisms

---

By the end, you'll understand how to design and troubleshoot distributed systems.
