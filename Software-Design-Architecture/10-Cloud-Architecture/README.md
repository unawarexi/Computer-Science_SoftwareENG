# 10 - Cloud Architecture

Learn how to design, deploy, and manage systems in the cloud. This module covers the essentials of cloud platforms, serverless, and high-availability design.

## What You'll Learn

- AWS/GCP foundational services (Compute, Storage, Networking, IAM)
- Serverless vs serverful (Cloud-Native architectures)
- High availability, resilience, and disaster recovery
- Cost optimization (FinOps) and spot instances
- Infrastructure as Code (Terraform, AWS CDK)
- The Well-Architected Framework and Edge Computing

## Weekly Breakdown

**[Week 1: Foundational Cloud Services](./01-foundational-cloud-services.md)**

- IAM, EC2, VPC, S3, RDS, Cloud SQL

**[Week 2: Cloud-Native & Serverless Architectures](./02-cloud-native-serverless.md)**

- Serverless vs Serverful, AWS Lambda, Event-Driven Architecture, API Gateway

**[Week 3: High Availability Design](./03-high-availability-resiliency.md)**

- Multi-AZ, Load Balancing, Route53, Load Shedding, Disaster Recovery (RTO/RPO)

**[Week 4: Cost-Effective Architecture (FinOps)](./04-cost-optimization.md)**

- Auto-scaling, Spot instances, Reserved pricing, Storage lifecycle policies, Cost tagging

**[Week 5: Infrastructure as Code & Automation](./05-iac-and-automation.md)**

- Terraform, CloudFormation, AWS CDK, immutable infrastructure

**[Week 6: Well-Architected Framework & Advanced Topics](./06-well-architected-advanced.md)**

- The 6 Pillars, Multi-Cloud/Hybrid Cloud, CDNs (CloudFront), Edge Computing (Lambda@Edge)

---

By the end, you'll be able to architect and deploy systems in the cloud.
